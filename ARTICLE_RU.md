# 🇷🇺 Как мы сделали 100% русификатор Google AntiGravity 2.0 с живым автообновлением через MCP и CDP (без перезапуска IDE)

**Google AntiGravity 2.0** — одна из самых мощных агентных IDE нового поколения с поддержкой субагентов, фоновых автоматизаций, встроенного браузера и MCP-серверов. Однако из коробки весь интерфейс, настройки, карточки плагинов, статусы инструментов и системные меню доступны только на английском языке, а при каждом официальном обновлении IDE любые ручные правки затираются.

Мы решили эту задачу инженерно и создали открытый проект **[`antigravity-features-v2`](https://github.com/WiseYaroslav28/antigravity-features-v2)** — полноценную систему локализации и улучшения Google AntiGravity 2.0, которую **сама же AntiGravity может установить себе по одному промпту в чате** и далее обновлять на лету без участия пользователя.

---

## ⚡ Установка за 10 секунд (2 способа на выбор)

### Способ 1. Попросить саму AntiGravity установить русификатор себе (Self-Install Prompt)
Просто откройте чат в вашей AntiGravity, вставьте туда этот текст и нажмите **Enter**:

> ```text
> Установи полный русификатор и MCP-сервер автообновления AntiGravity 2.0 из репозитория https://github.com/WiseYaroslav28/antigravity-features-v2 — выполни в PowerShell команду:
> irm https://raw.githubusercontent.com/WiseYaroslav28/antigravity-features-v2/main/install.ps1 | iex
> ```

Агент сам скачает проект, пропишет себя в `mcp_config.json`, соберёт патч `app.asar` и мгновенно переведёт открытое окно IDE на русский язык!

### Способ 2. Одной строкой в PowerShell (даже без установленного Git)
Откройте **PowerShell** и выполните:

```powershell
irm https://raw.githubusercontent.com/WiseYaroslav28/antigravity-features-v2/main/install.ps1 | iex
```

## 🧠 Как это устроено внутри (Архитектура)

Обычные русификаторы для Electron-приложений ломаются на двух вещах:
1. **React перерисовывает DOM динамически** (и при первой же мутации сбрасывает переведённый текст обратно на английский или рвёт фразы на 3 отдельных текстовых узла вроде `<span>{498}{" of "}{500}</span>` или `<span>{100}{"% left"}</span>`).
2. **Официальный автоапдейтер AntiGravity** перезаписывает `resources/app.asar` при каждом релизе.

В `antigravity-features-v2` мы построили 4-уровневую архитектуру:

### 1. Умный DOM-транслятор на базе `MutationObserver` (`localization_injected.js`)
- **Двунаправленное переключение `EN | RU` за 0 мс**: в правом верхнем углу окна встраивается компактный переключатель **`EN | RU`**. Перед заменой любого текста, `placeholder`, `title`, `data-tooltip` или `aria-label` оригинальное значение сохраняется в `data-original-*`. При нажатии `EN` интерфейс мгновенно возвращается к оригиналу без перезагрузки страницы.
- **Защита кода, терминала и имён файлов (`shouldIgnore` + `isFileName`)**: жёсткий фильтр не трогает редактор Monaco (`.view-lines`), терминал `xterm`, блоки кода и пути к файлам, но при этом прицельно переводит динамические статусы шагов агента прямо внутри ленты чата (`Размышлял 12 сек`, `Исследован 1 файл`, `Найдено 29 субагентов`, `Выполнена команда`, `Шаг 498`, `3 быстрых вопроса`).
- **Сборка составных React-узлов**: корректно распознаёт случаи, когда React дробит фразу на несколько текстовых нод (`"Show " + 533 + " more..."` → `"Показать ещё 533..."`, `100 + "% left"` → `"100% осталось"`, `498 + " of " + 500` → `"498 из 500"`).

### 2. Нативный патчер `app.asar` с защитой компилятором V8 (`auto_patcher.cjs`)
Вместо внешних утилит патчер работает через `@electron/asar` и перед упаковкой прогоняет каждый изменённый файл (`dist/preload.js`, `dist/main.js`, `dist/tray.js`, `dist/menu.js`, `dist/updater.js`, `dist/ipcHandlers.js`) через `new vm.Script()` движка V8. Если хотя бы в одном файле обнаружится синтаксическая ошибка — сборка блокируется, что **на 100% исключает «белый экран» после обновления**.

Помимо локализации, патчер исправляет:
- **Сохранение геометрии окна на 2-м мониторе** (больше никакого сброса на основной экран в размер `1400×900` при старте).
- **Одиночный и двойной левый клик по иконке в системном трее Windows**.
- **Разворачивание из трея при повторном клике по ярлыку на рабочем столе**.

### 3. Фоновый MCP-сервер с автообновлением через GitHub (`index.js`)
Проект регистрируется внутри самой AntiGravity как штатный **MCP-сервер (`antigravity-features-v2`)**.
- При запуске IDE она сама стартует `node index.js`.
- Сервер по HTTPS проверяет [`version.json`](https://raw.githubusercontent.com/WiseYaroslav28/antigravity-features-v2/main/version.json) в репозитории GitHub (не требуя установленного `git`).
- Если вышла новая версия словаря — скачивает обновлённые файлы, проверяет их через `node --check`, пересобирает `app.asar.patched` и **тут же через Chrome DevTools Protocol (`127.0.0.1:9222`) на лету (Hot-Reload) инжектирует свежий перевод в открытое окно AntiGravity без перезапуска IDE!**

### 4. Ненавязчивый индикатор статуса и обновлений (`i` рядом с `EN | RU`)
Рядом с переключателем `EN | RU` расположена минималистичная иконка **`i`**:
- В штатном режиме она **спокойного серого цвета**, не отвлекая от кода.
- Как только на GitHub выходит новый релиз локализации или требуется перезапуск после обновления самой IDE — точка над `i` начинает **пульсировать жёлто-оранжевым цветом**, а при наведении открывается карточка с описанием изменений (`changelog`) и кнопкой обновления в 1 клик.
